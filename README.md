# PROJECT CASCADE v2

Пакет спецификации и отдельный Unity-проект `CascadeUnity/`, подготовленный в P00.
Первичный импорт и компиляция проверены на Unity 6000.3.8f1. Игровые системы ещё не реализованы.

1. Читать Docs/MASTER.md.
2. Unity-проект находится в `CascadeUnity/`. Авторские Docs/Data/Prompts/Tools/Reports и AGENTS/TASKS остаются в корне этого пакета, вне Assets; не дублировать их внутри Unity-проекта.
3. Сначала AGENTS.md и Prompts/P00.md; затем одна задача за раз.
4. Tools/ содержит исполняемую Python reference-модель; Reports/ — результаты выполненных проверок.
5. Не переносить механики другой игры; не перезаписывать пользовательские исходники и .meta.
6. Нет фонтов, платных ассетов, реальных рекламных IDs, API-ключей или Unity-билда.

Все значения — проектные. Численная проверка не доказывает удовольствие/retention.

Окружение и единственное исправление несовместимости шаблона зафиксированы в
`Docs/P00_SETUP.md` и `Docs/UnityProjectContext.md`. Результаты нового запуска —
в `Reports/P00/`; исходные отчёты сохранены. ShapeMania (`shape_sorting-final`)
подтверждена автором как визуальный ориентир для P12.
