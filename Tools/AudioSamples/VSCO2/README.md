# VSCO 2 CE — selected acoustic recordings

CC0 1.0 Universal. See LICENSE and sources.json for the full license, exact URLs and hashes.
Recorded by Sam Gossner / Versilian Studios and Simon Dalzell / Ivy Audio; sample cutting by Elan Hickler / Soundemote.
Official source: https://versilian-studios.com/vsco-community/
Repository: https://github.com/sgossner/VSCO-2-CE

These source recordings are used only by Tools/compose_acoustic_score.py, outside Unity Assets. No runtime sampler is shipped. Upright roots follow MIDI 21 + 2 × filename index; harp uses scientific octaves and cello uses the source library's octave labels (C1 = MIDI 36). Rendered arrangements are original CASCADE compositions.
