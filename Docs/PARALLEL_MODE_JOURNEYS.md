# Parallel mode journeys — 7 October 2026

The map is the only mode selector: Shapes / Words / Mixed. Start game goes to the opening story once, then to this map. Settings only select interface and word language. Old entry points redirect to the map; no second selection screen.

Save envelope schema 2 accepts schema 1. The existing root journey is assigned to its saved PreferredMode, without copying clears into the other modes. Two inactive journey slots retain clears/best stars and score, dialogue/lesson history, independent mastery-route statistics, director memory, attempt, exact descent stage and completion receipt. The active root remains the sole source for existing gameplay code; it never also appears in the inactive slots. A failed mode-switch save restores the old journey before mounting another attempt. Old StoryRoute attempts stay pinned; future levels follow the selected mode.

Account preferences, shop inventory, purchased entitlements and earned reward ledger remain shared. The first clear of a campaign node awards its account resources once across the three modes; each mode separately earns its own stars and records. Switching or replaying cannot farm coins/parcels. Existing prices and product IDs are unchanged.

Shapes uses the published shape-only sequence; Words uses the selected word-language sequence. Mixed visits all 160 campaign nodes: use the existing combined shape/letter binding when present, otherwise alternate published word and shape puzzles. No new puzzle rules or fabricated solver proofs. The story/lore is shared; progress in one tab does not unlock another.

Celebration paper is sliced from the existing alpha atlas into individual silhouettes, each an independent UI object with cosmetic gravity, drag, wind, tumble and delayed fade. This is presentation simulation, not gameplay physics. No composite confetti sheet is drawn. Reduced motion/effects-off suppress paper. Timings and activation remain tied to the already committed reward receipt.

Menu action surfaces use teal enamel or amber enamel with contrasting type. Numbered level tiles receive the same treatment instead of brown wood against the wooden workshop.
