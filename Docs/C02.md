## C02. Scope и то, что обязательно работает совместно

| Система | Полный MVP |
|---|---|
| Платформы | 1–3 в основном наборе; формат поддерживает 4 |
| Ряд | 3–8, преимущественно 4–6 |
| Действия | Adjacent Swap, Early Drop, бесплатные Undo/Retry, Hint через решатель |
| Основные устройства | Закрытая связь, ключ, хрупкое ребро, конвейер, бомба, ремонт, связанные пары |
| Небольшие дополнительные | Одноразовый мост, необязательная печать маршрута; входят в позднюю часть 40 задач |
| Контент | 40 проверяемых конфигураций, Shapes/Words/Mixed |
| Языки | EN основной, RU/UK дополнительно; язык интерфейса и задачи разделены |
| Инструменты | Авторский редактор, validator, solver, воспроизведение пути |
| Прогресс | Карта, четыре небольшие сборки по 10 узлов; лучшие маршруты |
| Визуал | Единый toy-like псевдо-3D; управляемые анимации, не физический исход |
| Позже базового пазла | Заказ на три новых победы, косметика, ежедневный архив |
| После проверки удовольствия | Реальная реклама/IAP и внешние SDK |

Серый технический прототип может начинаться с Swap/Drop и трёх устройств. **Но хрупкие связи и связанные пары больше не отложены неопределённо:** у них здесь точные правила, уровни и отдельные implementation tasks.

Исключено: штраф за «неправильный» с точки зрения близости к цели ход; случайная перестановка; исчезающие буквы; реальное время у бомб; слепота; инверсия управления; реальный физический разброс; холостой лёд ради ожидания; автоматическая фиксация уже правильных элементов.
