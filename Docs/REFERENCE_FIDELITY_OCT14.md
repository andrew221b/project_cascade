# Reference screen fidelity and solid timber support

The failed-level screen used another header and medal family, a compressed nested viewport, an overly thick bench, and the gameplay plank's generic decorative support heights. The latest reference requires its original sad pose, silver result symbols, a suspended parchment, and two separate retry/map actions. Approved differences remain: less greenery on buttons, sparse animated background islands, world-specific scenery/light/decoration, localization and live player values.

## Final implementation

- Failure uses one uniform 720×1280 layout against the full canvas. Legacy result controls stay hidden. Both upper and lower hemp cords terminate on the moving bench/results assembly; cord evaluation runs after its suspension update. Upper cords reach the physical viewport edge even when a tall phone leaves space above the uniformly scaled reference stage.
- Mika and the three medals reuse the supplied reference's pixels. `FailureReferenceSource.jpg` is an unchanged copy of the attachment. Small source regions are rendered through explicit contour meshes, with blue-sky removal on Mika only; no full-screen screenshot is used as the functional UI. Values, labels, language and actions remain runtime elements.
- The narrow bench, bare green/amber buttons and red-X scroll use a reference-guided transparent atlas. The parchment and original wooden heading reuse existing art. Medallions and their text columns share their centres.
- Original wooden header geometry is restored in Inventory, Items, Trophies, Shop, Pause and Remove Ads. Field-help retains its original header in every world. The shared header shader changes frame/foliage colours while protecting light paper and readable text.
- The help modal's shop caption now refreshes with the selected UI language, including when the modal is already open. The existing small-screen fixture asserts its EN/RU/UK caption as well as text fit.
- Failure's character, timber, decorative plants and cords receive the current world's lighting. The first world's calmer sky matches the supplied reference; existing world-specific islands remain separate animated scenery. Other world sky themes are retained.
- Authored sky clouds no longer pass through the solid-surface relief lighting branch. This removes sharp colour rims at cloud/blue transitions; workshop surface lighting and atmospheric mist are retained.
- Gameplay top geometry now meets the authored timber's opaque crown at each strip column. Piece feet and shadows use the same visible crown. This removes the long sky slit and floating support offset without changing puzzle state, commands, durability, surface effects or move rules. Mirror, roller, wind and damage artwork is preserved.
- Fixed blank subscription artwork: the three existing illustrations were imported as textures but loaded as Sprite assets. The runtime now wraps the original emblem, calendar and explanation scroll as cropped sprites, scales regions to actual imported texture dimensions, checks missing resources explicitly, and releases its created sprites. Store-price and subscription behaviour is preserved.

## Validation scope

`Cascade/Review/Reference Fidelity` runs with an isolated temporary profile, captures the failure screen and all supplied menu families, checks text overflow and failure actions/cord attachments, and then runs the existing gameplay reference fixtures. `Reports/ReferenceFidelityOct14` holds the screen comparison; `Reports/ReferenceFidelityBoardsOct14` holds ordinary, mirror, roller and wind timber in each wear/fracture state plus a real failed attempt, help and EN/RU/UK small-screen checks.

Full-viewport reference captures explicitly override the Editor simulator's safe insets; they do not remove production safe-area handling. Device builds and hardware performance profiling are outside this visual pass. Pixel identity of every background/animated frame is not claimed: approved thematic scenery, animation and runtime values necessarily differ from the static source.
