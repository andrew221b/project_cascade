## Что пока не подтверждено

Подключение ID не подтверждает реальные показы или выдачу наград. Тестовый режим сохранён, production-показы выключены. Существующие два теста подписи и защиты выдачи прошли; на настоящем устройстве и через Google callback в этой проверке запусков не было. У текущего подключённого Unity Editor другой проект, поэтому его состояние не изменялось.

Для обоих Rewarded-блоков в AdMob требуется настроить и проверить Server-side verification callback:

```text
https://cascade-sky-gardens.active-seed-4233.chatgpt.site/api/admob/ssv
```

Reward amount должен быть 1; размер игровой награды определяет существующий серверный каталог. Пара User ID / custom data для проверочного callback должна быть выдана сервером как действующее тестовое предложение, а не придумана в кабинете. Агент готовит её перед совместной проверкой; callback не считается проверенным по одному сохранённому URL. Нужны также проверка consent/возрастного сценария для заявленной аудитории 9+ и настоящие тестовые показы.

Ожидаемая частота interstitial и добровольный rewarded-поток не менялись. Правка Unity CASCADE_RECEIPT_VERIFIER_URL из Docs/CLOUD_REMAINING_MANUAL_OCT20_RU.md остаётся отдельной задачей подключения облака.
