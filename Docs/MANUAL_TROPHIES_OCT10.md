# Manual collectible appearance — 10 October

Collecting three legacy fragments previously auto-equipped the completed Mika look, including perpetual drifting foliage. Collection offered no removal for the Mika slot. Acquisition will now only grant ownership; a completed collectible shows where it lives and a direct link to its appearance controls. All Mika, scene and frame looks can be applied or removed explicitly. Removing the Mika look also stops its background flourish; the independent scene/frame slots remain as chosen.

This changes only automatic cosmetic activation, not rewards, prices, parcel recipes, ownership or gameplay. Existing saved choices and all original assets/IDs are retained. No migration or new save field is needed: the existing nullable EquippedGift slot represents an inactive look, like the scene/frame slots. Durable Mika changes use the same transaction/rollback pattern as the other slots. Cloud reconciliation must preserve an explicit removal and adopt account choices when joining, using the existing three-way equipment merge.

New reward copy is brief, localized EN/RU/UK, and applies both to completed legacy fragments and whole cosmetic rewards. Partial fragments and coins retain their own messages. Collection preview and inline Shop both expose Use/Remove; ownership and other independent slots are retained. The collection header also reserves a symmetric gap before its counter at Large Text sizes.
