## Окружение и подпись

- Активный MCP-редактор принадлежит DrillGame и не использовался для изменений. Flying Ladders собиралась отдельным batch-процессом Unity6000.3.8f1; работа соседнего проекта не останавливалась.
- UnityCLI обновлена сbeta12 доbeta14. Новая интеграция не устанавливалась.
- Xcode27 отклонил старые deployment targets12.0 у Pods. Для архива передан IPHONEOS_DEPLOYMENT_TARGET=15.6 — уже действующий минимум приложения; пакеты не обновлялись.
- Скрипт SDKmanager ломается на пробеле MY DISK. Во временной директории созданы физические копии bin-обёрток и ссылки на установленные SDK/NDK/JDK. Проверка sdkmanager --version дала16.0; установленные файлы SDK не патчились.
- Использованы существующие Apple Distribution certificate/profile и Android upload key. Временная отдельная keychain удалена вместе с её паролем; исходные ключи сохранены.
- В текущем Xcode altool не запускается из-за отсутствия Defaults.properties. IPA отправлена прямым официальным App Store Connect Build Upload API. Для этого IPA-файла Apple приняла checksum MD5; SHA_256 был отклонён до commit без повторной передачи файла.
