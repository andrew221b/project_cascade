## C03. Состояние и единственная истина

```text
LevelDefinition (immutable):
  PuzzleId, CampaignNodeId, SchemaVersion, RulesVersion, ContentHash
  InitialSymbolIds[], TargetSymbolIds[]
  TargetSegments[]       # тип, стартовый индекс, длина, WordId при необходимости
  Floors[]:
    BaseDurability
    OpenEdges[N-1]
    FragileEdges[]
    LinkedPair?          # два непересекающихся соседних ребра
    EntryTransform      # None / ShiftLeftOne / ShiftRightOne / MirrorNext
    Bomb?(slot, requiredSymbol, ticks, damage)
    Key?(slot, requiredSymbol, edgeToOpen)
    Repair?(slot, requiredSymbol, amount)
    OneUseBridgeEdge?
    OptionalStamp?(slot, requiredSymbol)

PuzzleState:
  Row[], ActiveFloor, Durability
  BombPhase, BombTicks
  KeyUsed, RepairUsed, BridgeUsed
  StampBits, DefusedCount, ExplodedCount, AbandonedCount
  Status(Playing/Won/Lost)

AttemptState:
  AttemptId, RouteLength, History[], HintUsed, UndoCount
  ActiveLocale, Mode, PinnedContentHash, RevealedHintStates
```

`SymbolId` определяет равенство. `TokenInstanceId` допустим для анимации, но не влияет на цель. Две одинаковые A взаимозаменяемы.

Примеры ID: `shape:circle`, `glyph:en:O`, `glyph:uk:І`. Круг и буква O — разные сущности. В данных reference используются краткие ID (`s:T`, `g:en:C`), импортёр сопоставляет их типизированному справочнику. В пределах одного пазла разные фигуры должны иметь различимые силуэты.

Позиции и скорости Unity не входят в состояние. Стабильное Playing-состояние всегда имеет положительную прочность. Нулевое/отрицательное значение существует только внутри транзакции до обрушения.
