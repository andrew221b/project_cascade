## Design note — начальная структура и версии

Пользователь подтвердил отдельный новый проект в `CascadeUnity/` внутри пакета
и локальный Git в корне пакета.
Это выбор нового места реализации, а не перенос или изменение ShapeMania.

Unity фиксируется на установленной `6000.3.8f1`. Выбран существующий локальный
шаблон `com.unity.template.urp-blank`, версия `17.0.14`, поставляемый с этим
редактором. Он соответствует направлению простых 3D-моделей и URP из C17.
Создание начальной конфигурации не должно обновлять пакеты других проектов.
Дополнительные SDK, рекламу, IAP, сетевые сервисы и второй MCP не добавлять.
Начальные версии шаблона сохранены в `Reports/P00/before_import_manifest.json`
и `before_import_packages-lock.json`; итоговые сравнения — в `project_integrity.json`
и `package_baseline.json`. Итоговый импорт завершился с exit 0.

### Обнаруженная несовместимость шаблона

Создание штатным Unity CLI прервалось на sandbox-запрете локального сокета UPM.
Повторный импорт с доступом к локальным службам подтвердил лицензию, но нашёл
ошибку пакета Input System: `InputSystemPluginControl.cs(47,25)`, CS0117,
`BuildTarget.ReservedCFE` отсутствует в Unity `6000.3.8f1`.
В шаблоне указан `com.unity.inputsystem@1.12.0`. В пользовательской ShapeMania
на той же Unity установлен `1.18.0`, текущая Console не содержит ошибок.
Выполнено минимальное исправление начальной конфигурации CASCADE —
зафиксирован только Input System на `1.18.0` через Unity Package Manager.
Это устранение воспроизводимой несовместимости пустого шаблона, а не обновление
игры или изменение игровых правил. Файлы пакета вручную не исправлять,
manifest вручную не переписывался. Остальные прямые зависимости шаблона сохранены.

Чтобы запустить API при ошибках компиляции, неизменённая официальная копия
Input System 1.18.0 из локального package cache временно использовалась как
embedded package. До Client.Add она перенесена за пределы Unity-проекта в
`Reports/P00/temporary_inputsystem_1.18.0~/`, исключённый из Git. Первая попытка
Client.Add с ещё встроенным пакетом была отклонена UPM; исправленная процедура
в `Assets/_Cascade/Editor/ProjectBootstrap/PackageRepair.cs` сначала архивирует
временную копию. Финальные manifest/lock указывают registry 1.18.0; embedded
override в проекте отсутствует. Helper не запускается автоматически.

URP и Test Framework — builtin-пакеты выбранного Editor. При сохранённых
запросах шаблона `17.0.1` и `1.4.2` Unity разрешила фактические версии `17.3.0`
и `1.6.0`. Это отражено в package lock; обновление других прямых запросов не
выполнялось. Для воспроизводимости сохраняются точная версия Editor и lock.

`Data/`, `Docs/`, `Prompts/`, `Tools/`, `Reports/`, `AGENTS.md` и `TASKS.md`
в родительской папке остаются единственными авторскими источниками. Они не
копируются внутрь `Assets/`. Во вложенном проекте должно быть явно указано,
где находятся эти источники. Импорт контента — отдельный последующий этап.

Правила, баланс, схемы данных, сериализованные ID и цены не изменяются.
Начальный проект не содержит реализации игрового процесса или новых визуальных
ассетов CASCADE. Генерация ассетов относится к соответствующему этапу после выбора
и проверки визуального референса.
