# Наборы монет: баланс, 13 октября 2026

Изменяется только ассортимент покупаемых монет. Цены предметов, доход за прохождение, лимит запаса и правила применения сохранены. Это исходная модель баланса для проверки на игроках, а не результат анализа удержания или продаж.

Множители цен — предложение для настройки магазинов. Реальные суммы и валюты клиент получает только из App Store / Google Play. Суммы в гривнах из референса не становятся ценами приложения.

Инструменты стоят 180, 120, 300, 240, 150 и 210 монет. Один экземпляр каждого из шести видов стоит 1230 монет. Полный запас пяти экземпляров каждого вида стоит 6150. Максимальный набор 1080 покрывает 87.8% первого комплекта или 17.6% полного запаса. Сама покупка, без накопленной игровой валюты и ранее полученных предметов, не покрывает даже один полный комплект всех шести видов. Инструменты расходуются, каждый вид применяется один раз за этап; общий лимит двух применений и ограничение оценки уровня остаются прежними.

Максимальный набор 1080 покрывает половину цены самого дорогого отдельного трофея (2160). Он не позволяет приобрести всю коллекцию: даже восемь первых базовых трофеев стоят вместе 2880, а полный покупаемый каталог значительно дороже. Эксклюзивные трофеи из посылок по-прежнему не продаются.

Доход новых уникальных прохождений: 20 за уровень плюс 50 за каждые десять (в среднем 25), дополнительно существуют посылки и повторы. Без дополнительных наград 240 соответствует примерно 9.6 прохождениям, 1080 — 43.2. Цена одного инструмента соответствует 4.8–12 таким прохождениям. Эти соотношения требуют проверки частоты использования и наград посылок на тестовой группе; доход автоматически не уменьшался.

Сохранён действующий запрет покупки монет, когда кошелёк уже содержит не меньше 2160. Сервер проверяет настоящий чек и выдаёт каждый платёж один раз; внешнее увеличение остатка не доверяется. Клиент, общий код Cloud Code и allowlist ReceiptVerifier используют одинаковые шесть IDs.

Новые продукты для регистрации как Consumable: `cascade.coins_720`, `cascade.coins_960`, `cascade.coins_600`, `cascade.coins_1080`. Старые `cascade.coins_240`, `cascade.coins_480` сохраняют прежнее количество. Перед живыми продажами: зарегистрировать продукты, настроить цены, обновить серверный модуль и verifier, проверить sandbox-покупку/повторную доставку/восстановление соединения. Локальное расширение каталога само по себе не регистрирует продукты в сторах и не публикует сервер.
