# Повторная проверка запрошенных изменений — 15 октября 2026

Изменения в исходниках сохранены. Проверка обнаружила оставшийся лимит запасов: магазин, посылки и серверная сверка разрешали хранить только пять предметов каждого типа. Этот потолок теперь снят. Использование предметов по одному, оплата покупок и атомарность сохранений остаются частью рабочей экономики. Цены, идентификаторы товаров и типы полей сохранения не менялись.

Проверки после прежнего сбоя инструментов завершены через Unity CLI в отдельной временной копии текущего проекта. Основная несохранённая сцена пользователя не сохранена, не сброшена и не закрыта. Восстановление доступности MCP основного редактора этим не подтверждается.

Доказательства:

Субъективная интересность всех уровней, стабильный FPS на физических телефонах/планшетах и показ рекламы через реальные сети не подтверждены автоматическими проверками. Обновление не опубликовано в рабочий сервер и не установлено в сборку на устройстве. Новый общий код экономики должен попасть и в следующую сборку клиента, и в обновлённый серверный модуль.
