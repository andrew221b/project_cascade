## C19. Унаследованные решения и исправленные ошибки

| Вопрос | Канон v2 |
|---|---|
| Игрок ловит отдельные падающие блоки | Нет |
| Одинаковые фигуры очищают поле | Нет |
| Слово исчезает после сборки | Нет |
| Один постоянный ряд и точный receiver | Да |
| Только Shapes и Words | Дополнено полноценным Mixed |
| EN отсутствует | Исправлено: EN основной, RU/UK дополнительно |
| 4–6 элементов как жёсткий максимум | Исправлено: 3–8, обычно 4–6 |
| Круг равен букве O | Никогда; разные namespaces |
| Fragile/Linked «когда-нибудь» | Встроены в полный MVP, данные, формулу, тесты и задачи |
| Fragile + Linked запрещено всегда | Разрешено по общей цене 1 + crossedFragileCount |
| Бомба повреждает буквы | Никогда; только платформу |
| У бомбы один отрицательный timer для всех исходов | Исправлено: отдельные причины и счётчики |
| Ключ может разрешить текущий нелегальный ход | Нет |
| Repair после clamp отрицательного HP | Нет; только signed aggregation |
| Ремонт отменяет Early Drop | Нет |
| Повтор уровня выдаёт монеты снова | Нет, ключ FirstClear стабилен |
| Смена локали даёт новую выплату за тот же узел | Нет |
| Mirror/кран/маршруты этажей | Сохранены как явно отдельное NEXT |
| Новые мост/печать | Небольшие отдельные правила, реализованы в reference |
| Физика принимает решение | Никогда |
| Все visual/monetization проверки выполнены | Не заявляется |
