# Исправление ввода после посадки — 9 октября

Продолжение: первые 14 опубликованных задач вводят механики в порядке реально показанных уровней, вместо повторного выбора первого урока через TeachingNode. Старые опубликованные рецепты этого начала сохраняются для проверки уже заработанных результатов. Перезагрузка этапов сохраняет признак прохождения кампании. За повторные полные прохождения предусмотрен отдельный резерв: 2 монеты за каждую достигнутую при повторе звезду, максимум 10 монет на один узел за всё время и все режимы. Повтор с двумя звёздами после первоначальных трёх даёт 4 монеты; ещё такой же повтор не выдаёт их снова, повтор на три звезды добавит только 2. Звёзды рекорда не уменьшаются; огоньки и подарки остаются наградами нового прогресса. Резерв подтверждается двумя разными полными прохождениями на сервере, с объединением по максимуму, а не суммированием устройств. Новые необязательные поля имеют нулевое значение для старых сохранений.

По сообщению игрока: подсказка предмета должна показывать проверенный обмен, сохраняя возможность экспериментировать и использовать Undo. Строгая практика остаётся только у уроков управления. Ожидающий скан новых механик не блокирует текущую практику; после посадки сканируется новая платформа и обновляются состояния кнопок. Ручной EarlyDrop с оставшейся после контактов положительной прочностью можно отменить в рамках прежних двух бесплатных Undo. Разрушенные платформы по-прежнему требуют ReturnHourglass. История восстанавливается атомарно до анимации; цены, лимиты, формат сохранения и идентификаторы не меняются.
