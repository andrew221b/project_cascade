# Перенос AdManagerPro из ShapeMania

По прямому запросу пользователя импортированы Scripts/Resources/Documentation уже используемого AdManagerPro. Сохраняется установленный официальный Google Mobile Ads Unity11.5.0; второй SDK и дубликаты native frameworks не добавляются. Пример сцены не импортируется. Runtime и Editor разделены asmdef; включён требуемый плагином ADS для Android/iPhone/Standalone.

Шесть существующих App ID / Interstitial / Rewarded ID Flying Ladders перенесены в MobileAdsSettings, testMode=0. Неиспользуемые banner/native/app-open/rewarded-interstitial ID оставлены пустыми. GoogleMobileAdsSettings содержит те же App ID.

AdManagerCore, RewardedAdManager и InterstitialAdManager владеют инициализацией SDK, загрузкой, повторными попытками и показом. NativeAdProvider сохраняется как совместимый мост игры для согласия/возраста, паузы и существующих подтверждённых транзакций; прямых SDK Initialize/Load/Show в мосте больше нет. В AdManagerPro добавляются узкие callbacks для открытия/earned/закрытия и передачи SSV options перед показом, а также очистка объектов и отмена устаревших загрузок при смене сцены. Начисления по таймеру/локальному показу для cloud-игрока не добавляются.

Новых цен, монетизационных правил, схем хранения, секретов или рекламных блоков нет. Запасная бесплатная помощь из предыдущего исправления сохраняется. Сборку/установку/публикацию пользователь пока не разрешал. Ограничение AdMob Requires review от смены интеграции не снимается автоматически; реальные показы требуют отдельной проверки на устройстве.

## Проверка

final-edit-ios: 35/35, final-play-ios: 26/26, final-play-android: 26/26. Настройки шести ID и их платформенный выбор проверены в runtime; App ID совпадают с GoogleMobileAdsSettings. Через установленный Google SDK Editor transport проверены загрузка, открытие, earned, закрытие, отмена устаревшей загрузки и запрет нового автозапроса после очистки владельца. Проверки Editor не заменяют native-показ и живой SSV на устройстве.

Изменены три runtime-файла импортированного плагина: callbacks для SSV/earned/opened/closed, generation-защита отменённых загрузок, coalescing и reset. Остальные runtime/editor файлы скопированы из ShapeMania; GUID сохранены, добавлены asmdef, .meta новых файлов созданы Unity. Все коллизии импортированных GUID исключены. UI игры не менялся. Ограничения AdMob не обходились, Test apps OFF и боевые ID сохранены.

Отчёт: Reports/AdManagerProMigrationOct29/verification.json. Новая сборка не создавалась.

## Исправление rewarded-иконки и дополнительная диагностика

После локальной установки пользователь сообщил об исчезновении значка видео. Тест воспроизвёл ошибку: PaintHintCounter связывал film icon с !HintVideoUnavailable. Это условие удалено; значок теперь определяется лимитом подсказок, реальным токеном и уже открытым состоянием. При действительно сохранённой бесплатной запасной помощи существующий баннер кратко сообщает об этом на EN/RU/UK. Unknown/DeadEnd/ошибка сохранения не объявляются успешной подсказкой; новый экран не добавлен.

В NativeAdProvider добавлены категориальные данные текущих стадий UMP/ATT/init и причина блокировки signed reward; отказ подготовки intent теперь получает собственную диагностику. CloudSyncClient.RewardBlockReason ничего не меняет в авторизации или выдаче. Явный SignedOut остаётся защитой существующей учётной записи; автоматического снятия флага, нового identity или локального начисления в облачный кошелёк нет.

Финальная проверка:16/16 iOS PlayMode,16/16 Android PlayMode,154 AccountFlowChecks с fake SDK и реальными client/config sources. Базовый тест до правки:0/1, ошибка ожидаемого film icon. EN/RU/UK мобильные кадры просмотрены. Независимое ревью выявило и помогло закрыть ложное сообщение для solver Unknown. Промежуточная компиляция нового теста выявила неуточнённый namespace HintStatus; исправлено до финальных успешных прогонов. Проверки не доказывают native fill/живой SSV.

Mac стал доступен: повторно прочитаны Requires review/Limited ad serving у обеих Flying Ladders и Ready/Ad serving enabled у ShapeMania. Раздел GDPR показывал создание первого сообщения без опубликованных строк. Подготовлен и сохранён один черновик на обе платформы, EN/RU/UK, EEA/UK/Switzerland, Do not consent ON, текущая политика на flyingladders.vickand.com. Publish отклонён автоматической проверкой как изменение рабочей юридической/рекламной конфигурации; пользователь получил точный отдельный запрос. Пока Draft, не Published. Это возможная причина остановки UMP, но код ошибки SDK телефона не получен.
