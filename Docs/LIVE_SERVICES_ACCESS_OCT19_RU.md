## Как работает вход

Обе кнопки Google/Apple открывают браузерный Unity Player Accounts, где игрок выбирает провайдера и возвращается в игру. Отдельные нативные SDK-окна Google Sign-In и Sign in with Apple пока не реализованы. Прогресс связан с Unity Player ID; одинаковый email не объединяет аккаунты автоматически. Полный вход на устройстве, синхронизация, покупки и удаление после подключения ещё предстоит проверить.

## AdMob — обновление 21 октября: шесть ID подключены

Владелец предоставил все шесть ID. Они уже сохранены в Configs/admob.json, игровых/SDK assets и серверном списке rewarded-блоков; актуальный отчёт — Docs/ADMOB_CONNECTION_OCT21_RU.md. Следующая историческая инструкция о создании блоков и отправке ID уже выполнена и не должна запрашиваться повторно. Реальные показы, SSV и consent ещё не проверены; тестовые переключатели сохранены.


Нужен кабинет **AdMob**, а не Google Ads для рекламных кампаний. Существующий Google Play JSON доступа к AdMob не даёт. Управляемого входа в кабинет AdMob сейчас нет; создание блоков и сохранение настроек кабинета пока требуют действий владельца.

1. AdMob → Apps: использовать приложения Flying Ladders для iOS и Android. Если их нет — Add app, соответствующая платформа, ещё не опубликовано в магазине. Bundle/package: `com.vickand.flyingladders`.
2. В каждом приложении → Ad units → Add ad unit: создать **Interstitial** и **Rewarded**. Для Rewarded: amount `1`, item `reward`. Не выбирать Rewarded interstitial.
3. В App settings взять App ID; в Ad units взять два ID блоков. Прислать:

```text
iosAdmobAppId:
iosInterstitialUnitId:
iosRewardedUnitId:
androidAdmobAppId:
androidInterstitialUnitId:
androidRewardedUnitId:
```

App ID содержит `~`, ID блока — `/`. Это публичные идентификаторы: их можно прислать сообщением. ID кампании Google Ads или Publisher ID их не заменяют.

Агент подключает эти значения к игре и серверной проверке наград. Автоматическая реклама — после каждого второго завершённого уровня; покупка отключения рекламы убирает только эти interstitial. Rewarded остаётся добровольной, в том числе для лутбоксов.

Для Privacy & messaging используется адрес политики:
`https://flyingladders.netlify.app/privacy/`.

После исправления и проверки сервера оба Rewarded-блока должны получить SSV callback:
`https://cascade-sky-gardens.active-seed-4233.chatgpt.site/api/admob/ssv`.
Агент готовит настоящие данные проверочного предложения; затем в кабинете требуется Verify URL → Use verified URL → Save. Сейчас callback не считается проверенным. Настройки согласия и рекламы для заявленной аудитории 9+ также остаются частью подключения; одних шести ID недостаточно для готовой рекламы.
