# Онлайн: только идеи, без реализации

1. **Общая переправа.** Каждый играет свою детерминированную задачу, а проверенные доставки зажигают фонари общего моста. Видна цель команды; можно участвовать в удобное время. Сервер должен проверять маршрут через тот же Resolve, учитывать один receipt и не принимать «победу» из клиентской анимации.
2. **Одна посылка — разные пути.** Недельная известная задача и одинаковые стартовые условия. Игрок делится воспроизводимым маршрутом; сравниваются число ходов и печать, а не скорость пальца или платный бафф. Undo/Hint отражаются в категории рекорда.
3. **Письмо другу.** Обмен добровольными испытаниями из проверенных задач. Отправитель выбирает цель и короткую игровую открытку; получатель может отказаться. Свободный чат, личные данные и срочные уведомления для детской аудитории не нужны.

Первая идея органичнее поддерживает путь к маяку; вторая дешевле для начального прототипа. Реальная сеть, серверная проверка, модерация, приватность и конкурентные рейтинги не реализованы. Текущие «маршруты» — локальные записи одного профиля, не глобальный лидерборд. Платная монетизация/случайные покупки не вводятся через этот документ.
