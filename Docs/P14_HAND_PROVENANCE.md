# Tutorial hand provenance

`CascadeArt/TutorialHand.png` is an original sprite generated with the built-in
image generation tool for CASCADE on 2026-10-05. The complete request is saved
in `Docs/P14_HAND_PROMPT.txt` and embedded verbatim in the PNG metadata.

The source is
`/Users/andrew/.codex/generated_images/01a1089e-7eaf-75a1-8066-dbfc48df27a1/exec-ccd8179e-89bf-4468-a19e-90f0152217f8.png`.
It was copied into the project; the original remains untouched. Native alpha
was preserved. Unity imports it as a single sprite, no mipmaps, alpha as
transparency, maximum texture dimension 256. No image pixel editing or copied
ShapeMania artwork was used.

The warm glove, mint cuff and brass detail match the existing workshop palette.
Its function is a non-interactive demonstration of an adjacent gesture. It
cannot send a gameplay command. Reduced Motion suppresses its travelling loop;
text and local focus feedback remain available.
