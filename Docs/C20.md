## C20. Codex: последовательность, scope и экономия контекста

Роли моделей: лёгкая для DTO, простого экрана, data validation; обычная coding для одного модуля; сильная reasoning для resolver/solver/save и независимого анализа ошибок. Названия и доступность моделей выбирать из установленного Codex; этот документ не подставляет выдуманные ID и цены.

Один task — маленькая ветка и набор затронутых файлов. Читать только указанные разделы. Не просить переписать проект ради одного визуального эффекта. После двух неудачных локальных исправлений — минимальный failing test и сильное ревью.
