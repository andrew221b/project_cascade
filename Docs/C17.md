## C17. Архитектура Unity и редактор

Выбранная линия — Unity 6 с зафиксированным локальным patch. Не заменять её Godot/Flutter и не обновлять пакеты в обычном feature-task. uGUI/TextMeshPro, общий Input adapter, один Tween adapter, собственное небольшое ядро.

```text
Assets/_Cascade/
  Domain/         State, Commands, FloorRules, Resolver, Objectives
  Solver/         BFS, graph metrics, HintQuery
  Application/    Attempts, History, Preview, ContentBinding, Campaign
  Presentation/   Input, ViewPool, EventPlayer, Screens, Audio/Haptics
  Content/        Imported immutable data
  Editor/         LevelEditor, Validator, Solve/Replay/Export
  Tests/EditMode/
  Tests/PlayMode/
Data/             levels, localized_levels, word packs, balance
Docs/             Cxx sections, MASTER
Prompts/          P00…
Tools/            Python reference, builder, tests
Reports/          Recomputed results
```

`Cascade.Domain` не зависит от UnityEngine, файлов, языка интерфейса и SDK. Solver вызывает тот же переход, а не упрощённую вторую версию правил. ScriptableObject — конфигурация; активный пазл не записывается в ассет.

### Editor workflow

Автор выбирает длину ряда и этажи, собирает target, перемешивает initial, кликает связи и устройства. Редактор показывает цену, входные эффекты и проблемные комбинации.

Кнопки: Validate, Solve, Replay, Show dead states, Test optional objective, Export. При сохранении: version/hash и проверка ссылок. Не заставлять автора писать каждый уровень в raw JSON.

Ошибки: другой multiset, ключ к уже открытому ребру без смысловой причины, пересекающиеся linked, bridge+key на одном edge, несколько entry transform, нулевая BaseHP, нужного символа нет в target, слово не соответствует сегменту, target-segments перекрываются/не покрывают весь ряд.

Предупреждения, а не автоматические запреты: учебный ключ срабатывает на входе, бомбу легко обойти, длинный ряд с множеством значков, высокая forcedness. Часть таких решений может быть намеренной.

### Save

Attempt pin-ит rules/content/locale. Save после command commit, не после tween. Хранить stable-state, history или проверяемый command-log, monotonically HintUsed, objective, reward receipts. После прерывания можно сразу показать final-state, не проигрывая заново входной конвейер.

При новой версии устройства старый набор не пересчитывать молча. Данные периода прототипа допускается архивировать отдельно; миграция не должна повторно начислять clear-награду.
