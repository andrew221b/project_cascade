## Авторизация и безопасный маршрут

Плагин Vercel возвращает403 для команды vickand; две свежие ссылки авторизации у владельца сразу показывали expired. Третья ссылка не предлагалась повторно. Существующий Vercel CLI не установлен/не авторизован. Публикация выполнена через уже авторизованный Cloudflare с сохранением Vercel-оригина. Административный доступ плагина остаётся отдельной проблемой, но не блокирует текущую рабочую форму.

Автоматическая проверка отклонила hostname-wide Worker wildcard из-за риска нарушить весь сайт. Он не создавался. Применена более безопасная альтернатива: ровно шесть узких маршрутов; отдельное HTTP-чтение подтверждает, что главная и ресурсы по-прежнему приходят с Vercel. Идентификаторы, sha256, привязка сервиса и откат описаны в Backend/WebFront/deployment.json и README.md.

Требования Google к веб-ресурсу удаления: https://support.google.com/googleplay/android-developer/answer/13327111 . Страница включает внешний от приложения путь запроса через support@vickand.com с проверкой владения; она не требует переустановить игру для отправки такого запроса.
