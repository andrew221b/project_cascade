# Screen clarity — 8 October 2026

The existing illustrated world stays. This pass replaces the information hierarchy,
not the game, economy or save format. One obvious next action; illustrations before
instructions; each price/state belongs to its object. Narrative dialogue remains.

- Teal enamel = action, gold wood = selected tab, ink = reading, papyrus = a
  specific explanation or object name. No cream cards behind whole screens.
- McLaren/Nunito remain the font stack. Fixed roles: 26 heading, 20 object name,
  18 action/body, 16 compact tab, 14 supporting caption. Large Text increases roles; no shrinking
  whole screens or uneven button captions. Use the common safe-area scale.
- 44 minimum touch target (48 for main actions), 12 between actions, 16 between groups, 16 reading inset.
- Home prioritises Play, Shop and Settings. Ads settings remain reachable under
  Settings. Map keeps reserved world-arrow slots, three modes and one star count.
- Tools show one short effect with their art, inventory quantity and a compact
  two-tool/two-star rule. Detailed effects remain in the animated guide.
- Journal, records and workshop use labelled illustrated facts/progress instead
  of repeated sentences. Purchase states explain money/test status once.
- All screens are reviewed from native Unity captures in an isolated profile.
  Small portrait and Large Text cases are included. Screenshots cannot establish
  comprehension by a real five-year-old or VoiceOver/device compliance.

No prices, gameplay rules, package versions, IDs or persisted schemas change.

Catalogue thumbnails now open a separate view within the same screen. Its Back
returns to the same shelf/category/page. The transient detail flag is not saved
as gameplay state; the existing parent navigation snapshot carries it when needed.
Long dialogue lines are paginated against the actual reading area, preserving
all words, speakers and original receipt IDs. Reading text does not shrink to fit.
Comic speech uses the same measured page splitting. The Next button reveals each
chunk before advancing speaker/illustration; no paragraph requires hidden scrolling.

The teaching pointer owns a separate sorting layer above menu graphics. Tool
teaching first points to its shelf object, then Use; contact uses the control
rectangle centre rather than its layout pivot. Other tool selections remain blocked.
