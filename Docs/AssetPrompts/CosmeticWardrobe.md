# Mika wardrobe assets — 7 October 2026

Four transparent PNGs in `CascadeArt/Cosmetics`, generated with Image Gen from
the existing Mika hopeful/thinking illustrations and the game's trophy art.
Existing source art and metadata were preserved.

- `SkyCourier`: blue woven scarf, indigo courier overalls, feather brooch.
- `MoonObserver`: indigo constellation cape, lavender overalls, moon clasp.
- `RainExplorer`: teal oilskin coat, green trousers, rain-cloud clasp.
- `AmbientAtlas`: two rows of four isolated sprites: leaf, warm mote, feather,
  star, petal, raindrop, amber leaf, firefly.

Wardrobe prompt constraints: recognisably the same warm squirrel Mika, same
face, fur, tail, proportions and brass lantern; complete hopeful and thinking
poses, equal separate cells in a wide atlas, generous clear centre gutter;
painterly tactile fantasy-game materials, clean RGBA silhouette, no text.
The first wardrobe drafts crossed the centre gutter; final regenerated wide
atlases replaced those drafts before import. No unused drafts are in the game.

Runtime uses one full pose or a cropped portrait, with preserved aspect ratio.
The five badge-only sets reuse the existing authored trophy icons, pinned to
Mika's scarf. Animated ambient sprites are separate objects, capped at ten.
