# Art direction
Reference: user My Items screen, 720×1280.
Backdrop: remove all UI and foreground objects, retain precise timber/rope/foliage frame, vivid sky, soft island castles and deep green valley, perspective stone steps. No static airborne leaves.
Blue spool: faithful isolated thick teal braided rope, honey wooden top and base, loose rope at sides and lower left; no arrow.
Pedestal: low pale ivory limestone display slab in gentle top-down perspective, transparent.
Storefront: small cream shop with red striped roof, warm wood and coin stacks, transparent.
Leaf blur is a native UI shader using the existing leaf sprite; no raster recolouring.
Wallet: compact honey-gold coin stacks with one upright five-point star coin, clean transparent alpha.
