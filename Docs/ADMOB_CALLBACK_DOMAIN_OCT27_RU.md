## Что опубликовано

В существующем Cloudflare аккаунте владельца создан отдельный Worker flying-ladders-admob-ingress. Единственный новый маршрут — https://vickand.com/api/flying-ladders/*. DNS, MX, три прежних Worker-маршрута и визуал сайта не менялись. Ответ основной страницы до и после совпадает по SHA256; на ней по-прежнему включена существующая защита Vercel. Новый API не перенаправляет на Vercel и доступен Google напрямую.

Обработчик передаёт исходный подписанный URL в CascadeAccount/UnityAdmobNotification. Проверка Google ECDSA, intent, игрока, блока, времени и уникальности транзакции, а также начисление выполняются в Unity. В Worker нет базы или приватных ключей Apple/Google. Unity-авторизация хранится только в secret bindings, query скрыт в журналах; заголовки авторизации не выводятся.

Временный сбой Unity получает retryable503, неверная подпись403, запрос без подписи400. HTTP200 выдаётся только после Accepted либо Verified/Test от Unity. Служебный тест Google не начисляет награду. Redirect для запросов к Unity установлен manual: Cloudflare не поддерживает error, а автоматически переходить с авторизацией на другой адрес нельзя.
