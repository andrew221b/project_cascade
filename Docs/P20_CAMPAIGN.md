# P20 — a longer journey on rules 2.0

Contract before new IDs/content and catalog extension, 5 October 2026.

Keep the original five JSON files, C01–C40 definitions, hashes, packages, prices and rules unchanged. Add C41–C160 as 120 structurally distinct shape puzzles, and their optional EN/RU/UK word bindings using existing dictionary entries with identical equality signatures. Bindings are alternative renderings of one node, not extra puzzles counted as new gameplay.

Store the extension as one new optional `campaign_extension.json` object with `levels` and `bindings` arrays. Import explicitly in the playable; the original import remains available to reference tests. New IDs remain stable after publication. Every new level gets a route idea, solver minimum, replay and completed graph metrics; stamp delivery has a separate objective proof. Reject unreachable, trivial <5 actions, search-budget Unknown and repeated structure including reflected/symbol-renamed copies. Counterfactual checks establish that the featured device changes the shortest route or blocks delivery when removed; that is not proof of enjoyment.

Eight regions: existing Wind Gardens (1–15), Rain Mill (16–30), Copper Orchard (31–40); Cloud Post (41–64), Glass Lagoon (65–88), Moss Archive (89–112), Snow Spire (113–136), Great Beacon (137–160). New regions progress from 5–9 actions to 9–14, include breathing-room tasks and optional stamp detours. Keep all original free hints and Undo. No timer pressure or paid prerequisite. Reuse established devices deliberately: prepare a landing rotation, save a one-use crossing, mend a cracked board, unlock a passage, plan linked pairs, choose bomb defuse/early exit, collect a stamp through a different route.

Runtime region art, story, weather and pictorial guidance are the following visual revision; content release is not a claim that those assets already exist. Long Reach stays a separate earned-tool design until its pure transition, solver, save and drag contracts can be verified. Do not insert a hidden exception into rules 2.0. Online remains design only.
