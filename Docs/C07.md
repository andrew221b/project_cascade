## C07. Два дополнения и отсеянные идеи

### Одноразовый мост — менять порядок действий

Одно ребро открыто, но после первой принятой перестановки через него закрывается. Drop его не расходует. Пустой/невалидный ход не расходует. Undo восстанавливает.

Мост не открывается ключом в том же уровне: один edge не может одновременно быть мостом и целью ключа. Связанный ход может использовать мост; он закроется после **обеих** перестановок.

Новый вопрос: «Нужен ли этот проход ещё раз?» Это отличается от хрупкости, где проход остаётся, но стоит дороже.

### Необязательная печать маршрута — вторая задача в знакомом пазле

На одном этаже показан контакт, который нужно посетить определённым символом. При посещении ставится одна печать. Символ не исчезает, состав цели не меняется, прочность не возвращается.

Основная победа не требует печати. После прохождения можно выбрать отдельный контракт «доставить цель и получить печать». Его решаемость и минимум считаются отдельно. Так повторное прохождение меняет маршрут, а не только цвет слова.

C35: обычная доставка за 2 команды, доставка с печатью за 4. Оба маршрута проверяются одним resolver с разными goal predicates.

### Сравнение кандидатов

| Кандидат | Решение | Причина |
|---|---|---|
| Одноразовый мост | EXTRA внутри полного набора | Один бит состояния, новый порядок использования прохода |
| Печать маршрута | EXTRA внутри полного набора | Дёшево создаёт новый маршрут на знакомом поле |
| Mirror | NEXT | Ясное единичное преобразование, но не требуется вместе с конвейером в MVP |
| Выбор направления конвейера | NEXT | Настоящий выбор, но добавляет отдельную команду и обучение |
| Кран для дальнего обмена | NEXT, только заработанный внутри задачи | Меняет граф; не превращать в обязательную покупку |
| Раздельная прочность левой/правой половины | Отложено | Существенно тяжелее читать смешанные 7–8 элементов |
| Физическое разветвление этажей | Отложено | Плохо помещается на портретном экране |
| Исчезающие совпавшие фигуры | Не входит в эту игру | Нарушает постоянство ряда и целевой multiset |
| Пассажир с уникальной личностью среди одинаковых букв | Отклонено | Скрытое различие одинаковых символов ломает понятность |
| Лёд, требующий подождать | Отклонено | Создаёт бессодержательные действия |
| Случайная подмена букв | Отклонено | Уничтожает прогноз и проверенное решение |

Совпадения можно когда-нибудь использовать в **отдельной мини-задаче с собственным названием и правилами**. В текущем документе и коде их нет.
